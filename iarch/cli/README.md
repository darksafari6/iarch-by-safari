# iarch/cli — command line tools

Reserved for the commands Parts 2 and 5 add: `iarch-theme`, `iarch-keybinds`,
`iarch-anim` and `iarch-doctor`. Each one reads user state through
`iarch.lib.configstore` and writes only generated files.

Nothing here may be renamed to an older product name; the conventions live in
`branding/product.env`.
