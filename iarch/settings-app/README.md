# iarch/settings-app — the glass settings application

Reserved for Part 4: a GTK4 + libadwaita application (`dev.safari.iarch`) that
edits `~/.config/iarch/settings.json`, renders the About → Open-source licenses
page from `data/licenses.json`, and calls the generators in `iarch/lib/`.

Until it ships, the same settings remain editable by hand in
`~/.config/iarch/settings.json`; the repository defaults in `data/` apply.
